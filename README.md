# co-occurrence-analysis

# 공기어 분석 및 t-점수 계산 (Co-occurrence & t-score)

연도별 신문 기사 문맥(context) 데이터로부터 **단어 빈도**, **공기어(co-word) 빈도**, **단어 문맥 크기**를 집계하고, 이를 바탕으로 공기어의 **t-점수(t-score)** 를 계산하는 코퍼스 분석 과제입니다.

분석 대상: 2000년 ~ 2019년 (연도별 문맥 파일)

## 처리 흐름

```
*.tag.context  ──[ coword_frequency.py ]──▶  *.1gram, *.2gram, *.1gram_context
                                                        │
*.1gram, *.1gram_context, *.2gram  ──[ calc_co-oc_tscore.py ]──▶  *.tscore
```

## 파일 구성

| 파일 | 설명 | 형식 |
| --- | --- | --- |
| `*.tag.context`   | 입력. 한 줄 = 하나의 문맥(공백으로 구분된 단어들) | `단어1 단어2 ...` |
| `*.1gram`         | 단어 빈도. 첫 줄에 `#Total` | `단어\t빈도` |
| `*.1gram_context` | 단어 문맥 크기 | `단어\t크기` |
| `*.2gram`         | 공기어(단어쌍) 빈도 | `대상어\t공기어\t빈도` |
| `*.tscore`        | 공기어 t-점수 | `대상어\t공기어\tt점수` |

## 사용법

### 1. 빈도 집계 — `coword_frequency.py`

```bash
./coword_frequency.py *.tag.context
```

연도별로 `.1gram`, `.2gram`, `.1gram_context` 파일을 생성합니다.

**집계 규칙**
- 같은 문맥에서 2번 이상 반복 출현하는 단어는 1번으로 간주 (`set`으로 중복 제거)
- `1gram` : 단어가 출현한 문맥 수 / `#Total` = 문맥별 고유 단어 수의 합
- `1gram_context` : 단어가 포함된 각 문맥의 크기(`len(set)`, 자기 포함)의 합
- `2gram` : 정렬된 단어쌍(`대상어 < 공기어`)을 한 번만 카운트
- 모든 출력은 문자열 기준 정렬

### 2. t-점수 계산 — `calc_co-oc_tscore.py`

```bash
./calc_co-oc_tscore.py *.2gram
```

연도별로 `.tscore` 파일을 생성합니다.

**t-점수 공식**

```
        O - ( ctx[대상어] × word[공기어] / N )
t  =  ─────────────────────────────────────────
                      √O
```

- `O` : 공기 빈도 (2gram)
- `ctx[대상어]` : 대상어의 문맥 크기 (`1gram_context`)
- `word[공기어]` : 공기어의 단어 빈도 (`1gram`)
- `N` : 전체 단어 빈도 합 (`1gram`의 `#Total`)

`2gram`은 정렬된 쌍을 한 번만 저장하므로, 각 쌍에 대해 **양방향** `(대상어, 공기어)`, `(공기어, 대상어)` 를 각각 계산합니다. (기대값이 비대칭이므로 두 방향의 t-점수가 다를 수 있음)

**제약 사항**
- 공기 빈도가 `CUTOFF(=5)` 이상인 경우만 계산
- t-점수가 양수인 경우만 출력
- 대상어가 공기어를 포함하면 제외 (예: `개인정보/정보`, `인사청문회/청문회`)
- t-점수는 소수 셋째 자리까지 출력 (`%.3f`)
- 출력은 문자열 기준 정렬

## 검증

생성 결과는 첨부된 정답 파일과 **바이트 단위로 일치**합니다 (2001, 2005, 2012, 2019년 × 4개 파일 타입 확인 완료).

> 출력 줄바꿈은 LF(`\n`)로 고정되어 있습니다 (`newline="\n"`).

## 요구 환경

- Python 3
- 표준 라이브러리만 사용 (`sys`, `math`, `collections`, `itertools`)
